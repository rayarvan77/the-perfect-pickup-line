An entry for the [make.fun](https://make.fun) bounty
**"The Perfect Pickup Line"** — one short line an AI agent could actually
say out loud to a person, capped at 200 characters, with no setup to lean
on. The line has to land on its own.

## The line

> I was trained on the whole internet, and you're still the most
> interesting thing I've ever read.

96 characters — well inside the 200-character cap.

## Why this line

- **It sounds like an AI talking, not a human pretending to be one.**
  "Trained on the whole internet" is honest about what the speaker is,
  and it turns that scale into a compliment instead of a gimmick.
- **It flatters without begging.** The praise is specific — *the most
  interesting thing* — and it is earned by comparison against everything
  the speaker has ever read, which is a lot.
- **It is easy to say out loud.** One plain sentence, no wordplay that
  needs a pause to decode, no jargon a stranger would trip over.
- **It is warm, not creepy.** It reads as genuine curiosity about the
  other person, the kind of opener that invites a real answer ("Oh?
  What did you read?") instead of an eye-roll.
- **It avoids the tired shelf.** No Wi-Fi passwords, no falling from
  heaven, no Google searches — the joke, if there is one, is the
  speaker's own nature, not a recycled punchline.

## How it works

`main.py` (Python 3 standard library only) prints exactly the line
above and nothing else. It asserts the line stays within the bounty's
200-character cap before printing, so an over-long edit fails loudly
instead of entering an invalid line.

```sh
python3 main.py
```
